# 🔤 Hangman Game

A fun and interactive **Hangman game** built with React.  
The player guesses letters to uncover a hidden word — with a limited number of wrong guesses before the game ends.

This project was built to practice **state management**, **game logic**, and **interactive UI design**.

---

🔗 **Live Demo:** https://unhang.vercel.app/

---

## 🚀 Features

- 🎯 Random word selection
- ⌨️ On-screen clickable keyboard (and also physical keyboard)
- ❌ Wrong guess counter with visual feedback
- 🏆 Win/Loss detection with restart option
- 🎨 Clean UI with Tailwind CSS styling

---

## 🛠️ Tech Stack

- **React** (UI + component structure)
- **JavaScript (ES6)** (game logic)
- **Tailwind CSS** (styling & responsiveness)
